# Planning docs

All AI-assisted planning artifacts for this project live here, in the order they were produced:

1. [`CONTEXT_CHATGPT.md`](./CONTEXT_CHATGPT.md), the original audit of the live zaplio.io site (structure, content, functionality) that kicked off the rebuild. Historical reference; treat exact copy/dates/numbers in it as unverified until cross-checked against the live site.
2. [`DESIGN_PLAN.md`](./DESIGN_PLAN.md), the validated design/build plan derived from that audit: stack, content model, phased build order, and the project's hard rules (no invented stats, certs, testimonials, etc.).
3. [`UPGRADE_PLAN.md`](./UPGRADE_PLAN.md), the design/content upgrade pass done after initial launch: light/dark mode, modern components, real content pulled directly from zaplio.io, and the Prisma/admin-panel addition. Includes the decisions locked in with the user and what was deliberately deferred.

Read `UPGRADE_PLAN.md` last if you only have time for one; it's the most current and links back to the others' context where relevant. New planning docs for future work should land here too, not at the repo root.
